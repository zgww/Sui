采用状态动作图来实现机器人的多维状态行为逻辑。

在前端界面上， 实现为一个画布， 画布上可以添加任意多个对象，放置在不同的位置上。 
画布本身可以缩放，平移


根据对象类型的不同，可能在画布上表现为 矩形， 菱形。 
对象与对象之间的关系 会用曲线来表示。
对象本身可以选中，  并在右边的检视器中可以检视对象的属性，并可以修改。

整个图需要可以保存，加载,可以保存为文件，不同的文件。也可以加载指定的文件。

圆形表示状态机, 矩形表示状态， 菱形表示动作。

最简单的图为:
状态1->信号迁移动作(收到某某信号，禁用状态,激活状态2)->状态2


多层状态图为:
状态1->信号迁移动作->状态2->状态机激活动作->状态机2->状态机2的中间状态->状态机2


状态机激活动作和普通的迁移动作的区别在于，  迁移动作会禁用输入状态然后激活输出状态，从而实现状态的流转，   状态机激活动作不会禁用输入状态， 只是激活目标状态，标记来源状态， 从而实现多状态同时存在。


每个激活的状态，都会去调用关联的动作。

状态机2在收到结束信号后，会找到激活者动作，并触发信号'sm_close'


每个对象都可以定义pin点，用来建立和其他对象的连接。 对象内部可以通过pin点拿到关联的对象。  至于用来做什么，视具体的对象而定。


pin点可以定义在左边还是右边。pin点都有自己的名称。 1个pin点可以引出多条线。


有这些类型的对象:

* 状态机
* 状态
* 信号迁移动作
* 状态机激活动作(一边连着状态，一边连着状态机， 还可以设定状态机完成后的迁移目标状态。)
