此系统可以同时管理多台机器人。


每台机器人在data/robot/id 都有自己的目录。

航点树的数据以.json文件存在于机器人目录下 WaypointsTree.json

航点树是一棵树，支持任意层级。 所有节点都可以有子节点，没有专门的叶子节点这个概念。


类定义如下
```typescript
class Node {
    children: Node[]
    parent: Node
    name: string
    enable = true
    id: string // 每个节点都有自己的 唯一id. 如果节点被复制粘贴，也要生成新的id
    nodeType: string // 节点类型，一般使用类型名
}
interface Pose {
    theta: number,//0.0,
    point: {
        "x": number,//-0.001,
        "y": number,//0.0,
        "z": number,//0.0
    }
}
// 航点
class WaypointNode extends Node {
    pose: Pose
    index: number//: 0
    type: number//: 0
}
class Ptz {
    focus: number, // 29892,
    zoom: number, // 1.0,
    tilt: number, // 0.0,
    pan: number, // 359.99,
    focal_len: number, // 535
}
// 动作点
class ActionNode extends Node {
    ptz_param: Ptz
    lift_height = 0.0
    thermometry_points =[]
    snap_shot_url: string // "http://192.168.62.62:18880/prod/robot/center/file/downloadFileById?file_id=6a5439973cfc437c3f869a53",
    // id": "c57585cee18020ade8f5dfb478de8597",
    type: number // 1000,
    steer_point_name: string// "高压室人员入侵"
}
// 测点
class TaskPointNode extends Node {
}

// 使用orb特征点进行校准
class OrbRegistration extends Node {
    refImageUrl : string // 参考图url
    ptz:Ptz
    lift_height = 0.0
    pose:Pose
}

```


每个节点都继承Node这个类, 
航点树里，可以无限分级。

每个节点都可以右键添加新的节点， 从注册的节点类型中选择并创建。
航点树管理页面，上面是工具栏，下面分成左右栏，左栏是航点树形视图，右栏是检视器。
航点树视图，可以点击选择节点， 然后在检视器里显示节点的信息，和节点提供的额外的控制元素。

工具栏有以下工具：
* 展开航点树
* 收起航点树
* 移动到选中航点
* 云台移到选中的动作点

在主菜单中增加航点树管理。 

航点树可以从inspection.json中导入，并生成航点树,供后续编辑使用。 需要特别注意id是要对应的。
