还是采用节点树的方式编排多层状态机

数据树:
指令:
    最后一条手控指令的时间戳
    目标点

Idle状态
    动作:信号迁移('执行任务', '')
    动作:信号迁移('电量不足', '去充电状态')
    动作:检查有无完成的任务(有=>'任务中状态')

任务中状态
    迁移动作('enter', 
        取出下一个任务 => 子状态'移动到航点', 
        无下一个任务 => 父状态'idle'
    )

    移动到航点状态
        动作：信号迁移('到位', '移动到测点')
        动作：移动到目标点
    移动到测点状态  
        信号迁移（'云台到位', '执行动作状态')
        动作：移动到测点
    执行动作状态
    
    

去充电状态
    移动到充电桩状态
    就位状态
    充电中状态
    充电超时状态

手动控制状态
    动作：检查手控指令超时(超时=>'idle')
