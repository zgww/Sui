# 测点档案：十轮测试与发布验收

日期：2026-09-17。目标：单套 FMS 不超过 10,000 测点，以 JSON 保存基础档案，以 SQLite 保存航点绑定和任务引用。测试数据均为隔离合成数据，没有使用或导入现场站点数据，没有执行真实机器人控制。

## 十轮测试

| 轮次 | 范围 | 验证内容与结果 |
|---|---|---|
| 1 | Schema 与旧字段兼容 | 13 cases + 17 subtests：字符串 ID、父关系、字段类型、未知扩展、重复键、NaN、关系字段拒绝，通过。 |
| 2 | 缓存与查询 | 初始12 cases；优化后增加3 cases：分页、组合筛选、层级树、无文件重读、深拷贝隔离、名称索引更新，通过。 |
| 3 | 原子发布与并发 | 10 cases：同版本竞争、旧版备份、replace 故障、发布后恢复、跨进程单写锁、引用保护，通过。 |
| 4 | SQLite 关联和任务 | 13 cases：绑定校验、删除保护、地图替换保护、任务配置快照不随后续编辑改变、旧协议保持，通过。 |
| 5 | HTTP API | 17 cases：401/403、422/428/409、CRUD、预览不写入、导出、绑定筛选和不可用状态，通过。 |
| 6 | ARM64 前端生产构建 | Docker 内执行 tsc -b && vite build，通过；保留既有资源包体积提示。 |
| 7 | 浏览器操作 | 隔离预览环境实际登录、空态、JSON预览和发布、编辑、刷新持久化、新增、搜索/重置、站/电压/间隔/设备树、启停、航点绑定增删，均通过；未观察到浏览器错误。 |
| 8 | 万点容量 | 10,000 点、50条分页、10并发、真实TCP独立服务进程；结果见同目录 ARM64 性能报告。首次未达性能建议目标；优化后稳定查询 p95 65.28 ms、重载中位 1155 ms，达到建议目标。冷批次最大116.68 ms单列，鉴权替身及空绑定表限制见性能报告。 |
| 9 | 升级与恢复 | 10 cases：旧 SQLite 自动补列并保留数据、重复迁移、空档案初始化、损坏档案不覆盖、启动/关闭异常释放写锁，通过。 |
| 10 | 全量回归 | 最终177 passed +17 subtests，12.04 s；包括原有机器人状态机/仿真测试，4条既有弃用警告。日志 full-regression-final.log。 |

## 范围与限制

- 测试通过不等同于真实机器人现场联调；外部设备调用在相关测试中使用替身。
- 浏览器已触发导出且无报错，内置浏览器没有提供 Blob 下载事件；未据此声称文件已落到用户下载目录。导出 HTTP 内容及往返校验由 API 测试覆盖。
- Excel、模板克隆及告警模板关系未纳入本期，界面明确禁用。其他业务下沉页面可能仍是旧静态原型，本次仅将测点档案接入真实服务。
- JSON 全量导入会替换基础档案，先预览，再以 revision 发布；已被绑定或历史任务引用的测点不能直接移除。
- 单写进程；部署保持一个后端 worker/副本。未知字段保存在 extensions，不直接丢弃。
